# Bonemia

Accède aux abonnements premium pour moins cher.

Canva, Netflix, Spotify, ChatGPT, Claude Code et bien d’autres…  
Bonemia gère les abonnements numériques pour vous permettre d’y accéder à un prix plus accessible, dès aujourd’hui.

---

## 🎯 Objectif du projet

Bonemia a pour mission de démocratiser l’accès aux services numériques premium en proposant :
- des prix réduits,
- une gestion simplifiée des abonnements,
- une expérience utilisateur fluide et sécurisée.

---

## 🧩 Fonctionnalités clés (en cours / prévues)

- Catalogue d’abonnements numériques
- Paiement local et international
- Gestion centralisée des abonnements
- Support client
- Interface multilingue (Français / English)
- SEO optimisé
